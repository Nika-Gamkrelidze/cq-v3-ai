audio-edit-core.js — self-test

These assertions need a real Web Audio implementation (OfflineAudioContext, AudioBuffer), which the Python test suite has no way to provide — so this is a page you open rather than a pytest file. It lives in frontend/tests/, OUTSIDE frontend/public/, so nginx never serves it: the deployment gets the editor, not its test harness.

Run it after touching audio-edit-core.js: open this file directly (file:// works — nothing here needs the API), or serve the repo locally. Every operation is checked for what it does to LENGTH, to the SAMPLES, and to the channels it should not have touched.
